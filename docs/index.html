How this is scored

For each market Claude researches the question on the web without seeing the market's price and writes down a chance of YES. Then it sees the price and gives a final answer from the same research. Both numbers, the market's price and Claude's reasoning are pushed to a public GitHub repo before any order is placed; the "verify" link on each forecast opens GitHub's own record of when that push happened.

When a market settles, each forecast gets a Brier score: the squared gap between the forecast and what happened (0 is perfect, 0.25 is a coin flip). The market's price at the time is scored the same way, over the same markets, so the two are directly comparable. Forecasts whose research ran into betting odds are left out of the "before seeing the price" row.

Which markets: news, politics, entertainment, science and company events that close 3 to 14 days out, with fee-free maker orders. Markets that resolve on a live data feed Claude can't read (such as AI model usage rankings on OpenRouter) are skipped, because a forecast there would be a guess, not a judgment. This rule was set before the first forecast was published.
